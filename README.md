## ✨ Key Features

<br/>

### 1. ⏱️ High-Precision Pomodoro Focus Timer
- **Multi-Mode Cycles**: Seamless switching between Focus (25m), Short Break (5m), and Long Break (15m) sessions.
- **Accurate Time Interval Engine**: Drift-compensated countdown timer running reliably in foreground and background tabs.
- **Audio & Visual Cues**: Ambient progress rings, circular indicator feedback, and cycle completion state triggers.

### 2. ✅ Dynamic Task Manager & Priority Workflow
- **Instant CRUD Operations**: Rapid task creation, completion toggling, and deletion with zero page reload.
- **Priority Categorization**: Color-coded priority badges (High, Medium, Low) for instantaneous visual hierarchy.
- **Filter Tabs**: Instant filtering across All, Active, and Completed tasks with live count indicators.

### 3. 🎯 Daily Goals & Progress Metric Synthesizer
- **Visual Progress Tracking**: Real-time progress bar computing completion percentages across daily objectives.
- **Persistent State**: Automatic serialization to browser `localStorage` ensuring continuity across user sessions.

### 4. 🌤️ Real-Time Clock, Date & Ambient Weather Synchronization
- **Live Digital Clock**: Continuous real-time hour, minute, and second updates with localized calendar date formatting.
- **Weather Widget Integration**: Contextual temperature, condition icons, and ambient greeting messages matching time-of-day.

## 🚀 Quick Start & Local Setup

### 1. Clone the repository
```bash
git clone https://github.com/Rishikesh-Kumar811/zenith-dashboard.git
cd zenith-dashboard
```

### 2. Launch with Live Server
Open `index.html` directly in any modern browser, or run via local server:

```bash
npx serve .
```

Visit `http://localhost:3000` in your web browser.
